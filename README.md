
README: Spreadsheet Implementation in Java
This project is a Java-based spreadsheet implementation for the I2CS ArielU 2025A course.
It supports basic spreadsheet functionality, including dynamic cell evaluation, arithmetic formulas, and text or numeric inputs.
The system handles errors such as circular dependencies and invalid inputs, and allows saving/loading the spreadsheet state. With features like cell referencing (e.g., =A1 + B2).
